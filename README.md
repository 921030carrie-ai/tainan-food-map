# 台南美食地圖網站 (Tainan Food Map)

一個純前端、零建置工具、可直接部署於 GitHub Pages 的台南在地美食探索地圖網站。

## 功能特色
* **互動式雙向地圖連動**：整合 Leaflet.js 與 OpenStreetMap，點擊圖釘與店家卡片可即時互相定位與高亮。
* **多維度即時篩選**：支援關鍵字搜尋、台南市行政區篩選、價格區間篩選與 8 大美食分類快速切換。
* **手機優先響應式設計**：手機端提供一鍵切換「列表模式 / 地圖模式」懸浮按鈕；桌面端採雙欄分割螢幕瀏覽。
* **防破圖預設機制**：內建 `./assets/images/placeholder.webp` 預設占位圖，尚未準備店家照片也能整齊呈現。

## 如何新增店家
請參閱 `AGENTS.md` 第 4 節與第 5 節規範，直接編輯 `data/stores.json` 新增物件即可自動渲染上線。
